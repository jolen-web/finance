How Receipt Extraction Works
  1. With Your API Key: Your personal Gemini API key is used for receipt processing (your quota)
  2. Fallback: If your key fails or is rate-limited, the system uses the shared API key (if available)
  3. OCR Only: If all API keys are unavailable, the system uses optical character recognition (OCR) combined with regex patterns
  4. Manual Entry: You can always manually enter transactions if extraction fails
Benefits of Adding Your Own API Key
  • Higher rate limits for receipt processing
  • Better reliability - independent quota from other users
  • Faster extraction when using Google's Gemini API
  • Full control over your API usage

Need Help?

Follow these steps to get your API key:

  1. Visit Google AI Studio
  2. Click "Get API Key"
  3. Select or create a Google Cloud project
  4. Copy the API key
  5. Paste it above and click "Save API Key"
  6. Click "Test API Key" to verify it works

Your API key is stored securely in your user profile and never shared with other users.
